# Мобильная версия для менеджеров: план работы и тесты

Составлен 22.11.2026. Источники: четыре независимых плана (Claude Opus 5.5,
GPT-5.6 Sol, Grok 4.7) и их сравнение моделью Fable 5.2 со сверкой по коду.
GPT-6.2 Astra не запустилась: в Codex с аккаунтом ChatGPT она недоступна.

## Что хотим получить

Менеджер с телефона:
1. узнаёт о новой заявке и новом письме по своему лиду;
2. быстро оставляет комментарий;
3. смотрит свою базу лидов;
4. одним-двумя нажатиями звонит, пишет, ставит задачу, меняет стадию.

## Ограничения, о которых надо знать заранее

- **Письмо придёт с задержкой до 5 минут**, это задаёт синхронизация почты, а не колокольчик.
- **Системные уведомления на телефоне в фазе 1 не появятся.** На iPhone их даёт только
  установленное на экран «Домой» приложение (PWA) с iOS 16.4 и новее, на Android нужен
  service worker. В фазе 1 менеджер видит колокольчик и счётчик, когда открывает CRM.
- Все формы назначают заявки на Дмитрия, а его Gmail не подключён: о заявках он узнает,
  о письмах — нет, пока не подключит почту.

## Фаза 1: уведомления + удобная карточка (3–4 дня)

### Ф1.1 Бэкенд: новые виды уведомлений
- Вид `lead_inbound` вместо `system` в `_notify_workspace_admins`. Если админ и есть
  владелец лида, слать одно уведомление, а не два.
- Вид `email_inbound`: в `processor.py` в ветке `direction == "inbound"`, после
  сохранения новой входящей Activity. Получатель — `lead.assigned_to`, не владелец
  почтового ящика. Исходящие не уведомляют. Нет владельца — не шлём.
- Оба вида добавить в `DEDUP_EXEMPT_KINDS`.
- В тексте уведомления — название компании и тема письма, без тела письма.

### Ф1.2 Колокольчик
- Немедленно обновлять при возврате на вкладку, фокусе и восстановлении сети.
- Счётчик непрочитанных в заголовке вкладки: «(2) DrinkX CRM».
- Подписи и цвета новых видов в `KIND_LABEL` / `KIND_STYLE`.
- Клик по уведомлению открывает карточку лида.

### Ф1.3 Карточка лида на телефоне (`md:hidden`)
- Липкая нижняя строка: Позвонить · Комментарий · Задача · Стадия.
  «Позвонить» — `tel:` основного контакта; «Комментарий» и «Задача» переключают
  существующий композер в нужный режим и прокручивают к нему.
- Композер над клавиатурой, учитывает safe-area.
- На телефоне Enter — новая строка, отправка кнопкой.
- Черновик комментария не теряется при ошибке отправки и уходе со страницы.

### Ф1.4 Список лидов
- Ничего не строим: используем текущий мобильный `/pipeline`. Улучшения — по отзывам.

### Ф1.5 (если останется время) Системные уведомления на компьютере
- Кнопка «Включить уведомления» в колокольчике; при новых `lead_inbound` / `email_inbound`
  и скрытой вкладке — системное окошко со ссылкой на лид. Только для новых id, без дублей.

## Фаза 2: телефон как основной инструмент (4–6 дней)

- Нижняя панель навигации на телефоне: Сегодня · Мои лиды · Задачи · Ещё (safe-area).
- «Мои лиды»: поиск, чипы стадий, сортировка по ближайшей задаче/просрочке, кнопки
  «Позвонить» / «Написать» прямо в строке. Основа — `PipelineList`.
- Смена стадии и закрытие сделки — нижней шторкой.
- После звонка «Как прошло?» (Дозвонился / Не дозвонился / Перезвонить) → черновик
  комментария и предложение задачи. Сохраняет человек, без автодействий.
- Выбор канала «Написать»: почта / Telegram — на готовых хуках `use-lead-inbox.ts:33,51`.

## Фаза 3: уведомления при выключенном экране (4–6 дней + устройства)

Начинать, только если фаза 1 показала, что колокольчика мало.
- PWA: manifest, иконки, service worker без кеширования страниц.
- Web Push: VAPID-ключи в `/opt/drinkx-crm/shared/.env`, таблица подписок
  (пользователь, устройство, endpoint, ключи), отправка Celery-задачей после commit
  уведомления, удаление протухших подписок (ответ 410).
- Экран «Установить на телефон» с инструкцией для iPhone.
- На заблокированном экране — минимум данных клиента.

### Обязательные проверки перед PR
`npm run typecheck`, `npm run lint`, `pnpm build` в `apps/web`;
`python -m py_compile` по изменённым модулям и `pytest` в `apps/api`.

### Ручная проверка
- Браузер на 375 и 390 px: карточка лида, композер с открытой клавиатурой, нижняя строка
  не закрывает поле ввода.
- Отправить тестовую заявку с формы дважды подряд: оба уведомления в колокольчике.
- Тестовое письмо на подключённый ящик: уведомление владельцу через ≤ 5 минут.
- Фаза 3: реальный iPhone (iOS 16.4+, установленная PWA) и Android Chrome — фон,
  выключенный экран, отзыв разрешения, переход по уведомлению после повторного входа.
