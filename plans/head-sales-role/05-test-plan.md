## Manual smoke checklist (для product owner, в браузере)
1. Как руководитель: «База лидов» → отметить 3 карточки → «Выдать менеджеру» → выбрать себя или менеджера → тост «Выдано карточек: 3».
2. Там же: «Выдать N по фильтру» с фильтром города → число реально выданных в тосте.
3. «Задачи» → «Новая задача» без лида → исполнитель менеджер → задача в «Поставлено мной».
4. Вкладка «Команда» → фильтр по исполнителю → «Просрочено».
5. Как менеджер: «База лидов» без галочек; «Задачи» без вкладки «Команда»; задача от руководителя в «Мои», закрывается галочкой.
6. `/today`: галочка на задаче без лида — закрывается, строка не кликабельна.
7. Карточка лида → «Задачи» → карандаш → сохранить — лента обновилась.
